# 世界系统优化方案 v1

## 一、问题回顾（6+4）

上一轮分析识别出 **6 个设计问题** 和 **4 个玩家痛点**，归纳为三条核心矛盾：

| 核心矛盾 | 涉及问题 |
|----------|---------|
| **A. 玩家无力感** | 10%漂移率吞噬玩家行动效果；分支标记从未被触发；大国行动数值太小 |
| **B. 内容悬崖** | 幕后执政硬门槛→前40-60回合世界页空白→解锁后内容爆炸 |
| **C. 子系统孤立** | 贸易与远征互不影响；大国外交与贸易/远征无有效联动 |

---

## 二、优化方案总览

```
优化1: 大国外交 → 从"旁观者"到"棋手"
优化2: 世界内容 → 从"悬崖式解锁"到"渐进式展开"
优化3: 贸易系统 → 从"多步骤搬运工"到"路线经营"
优化4: 远征系统 → 从"打地鼠"到"战略征服"
优化5: 系统耦合 → 从"平行线"到"反馈环"
优化6: 信息呈现 → 从"数据墙"到"态势感知"
```

## 三、各项优化详细设计

### 优化1：大国外交——从"旁观者"到"棋手"

**现状问题**：
- `DRIFT_RATE = 0.10`，玩家每次行动影响经济±3-5，但漂移每季抹平10%差距，效果几乎不可见
- 8个行动中分支标记（`_branch_war_accelerated` 等）从未被任何行动设置
- 合作度（-100~+100）只有展示标签的作用，没有实际游戏影响

**改动方案**：

#### 1.1 降低漂移率，引入"玩家影响力衰减"替代

```
文件: scripts/data/powers_data.lua
改动: DRIFT_RATE 从 0.10 降低到 0.03
```

理由：0.03意味着每季缩小差距3%，一年后（4季）约12%。玩家一次经济制裁(-3 economy)在4季后仍残留约 2.6，而不是现在的几乎归零。玩家会感知到"我的行动确实在改变大国走向"。

同时添加一个新机制——**"干预惯性"**：当玩家连续3季对同一个大国执行同方向行动时，效果叠加20%。这鼓励玩家持续投入一个方向，而非每季随机操作。

```lua
-- player_actions_gp.lua 新增逻辑
-- 在 ExecuteAction 中，记录连续同方向操作计数
local streakKey = powerId .. "_" .. action.stance
local streak = state._action_streaks or {}
streak[streakKey] = (streak[streakKey] or 0) + 1
-- 对其他方向的计数重置
for k, _ in pairs(streak) do
    if k ~= streakKey and k:sub(1, #powerId) == powerId then
        streak[k] = 0
    end
end
state._action_streaks = streak

-- 连续加成：第3次起，+20% 效果
local streakBonus = 0
if streak[streakKey] >= 3 then
    streakBonus = 0.20
end
```

#### 1.2 激活分支标记——让玩家行动真正改写历史

现有6个分支标记代码完整但无触发器。方案是将其绑定到具体的**合作度阈值 + 关键年份事件**：

| 分支标记 | 触发条件 | 年份窗口 |
|---------|---------|---------|
| `_branch_war_accelerated` | `collaboration_score ≥ 30` 且向奥匈执行 `share_intel` | 1913-1914 |
| `_branch_war_delayed` | `collaboration_score ≤ -20` 且累计对大国执行3次 `economic_sanction` | 1913-1914 |
| `_branch_war_prevented` | 极端路线：5次 `currency_war` + 总影响力 ≥ 200 | 1912-1913 |
| `_branch_ah_federalized` | 合作路线：对奥匈好感 ≥ 50 + 合作度 ≥ 40 | 1916-1917 |
| `_branch_yugo_neutral` | 对南斯拉夫好感 ≥ 30 + 执行 `shelter_refugees` ≥ 2次 | 1940-1941 |
| `_branch_self_liberation` | 抵抗路线：合作度 ≤ -50 + guards ≥ 25 + 支持游击队 ≥ 3次 | 1943-1944 |

**实现位置**：在 `GrandPowers.Tick()` 的 Step 4/5 之间新增一步 `_CheckBranchTriggers(state, year, quarter)`。

**关键设计原则**：每个分支都需要**前期积累**（合作度/行动次数）+ **窗口期内的具体行动**。不是一个按钮触发，而是长期策略的回报。

#### 1.3 合作度的实际影响

当前合作度只有标签。改为**影响游戏终局评价和中期事件**：

| 合作度区间 | 游戏内效果 |
|-----------|-----------|
| ≥ 30（合作者） | 占领期间维护费-30%，但解放后被清算：影响力-20，随机失去一个矿 |
| 10~29（偏向合作） | 贸易订单价格+10%（大国给好价） |
| -9~9（中间路线） | 无特殊效果 |
| -10~-29（消极抵抗） | 远征制裁阈值+3（大国更容忍你） |
| ≤ -30（人民英雄） | 解放后影响力+15，解锁独有称号"民族脊梁" |

**实现**：在 `TurnEngine` 每季结算时根据合作度应用对应 modifier。

### 优化2：世界内容——从"悬崖式解锁"到"渐进式展开"

**现状问题**：
- 幕后执政门槛（3区控制≥70、总影响≥60、guards≥15）在40-60回合才可能达成
- 达成前：世界Tab只有"地图"和"大国势力"两个展示性子标签
- 达成后：贸易+远征+海外开采同时涌入

**改动方案**：

#### 2.1 分层解锁取代单一门槛

取消幕后执政对贸易/远征的硬性门控，改为**分层渐进解锁**：

| 解锁阶段 | 条件 | 开放内容 |
|---------|------|---------|
| **第1层：情报网络**（~第8-12回合） | 总影响≥20 或 任意1区控制≥50 | 大国外交行动（当前的4姿态8行动）+ 简化版世界报告 |
| **第2层：贸易通道**（~第16-24回合） | 获得称号"商业新秀"(cash_earned≥5000) 或 总影响≥40 | 贸易系统（接单/发货）|
| **第3层：远征资格**（~第32-48回合） | 获得称号"幕后执政" | 远征系统 + 海外开采 |

**实现**：
```
文件: scripts/data/titles_data.lua
改动: 为 shadow_ruler 的 unlock_features 中移除 "foreign_trade"
新增: 在 "商业新秀" 称号中添加 unlock_features = {"foreign_trade"}

文件: scripts/systems/trade.lua
改动: CanDoForeignAction 检查 unlocked_features["foreign_trade"]（不变）

文件: scripts/systems/grand_powers.lua
改动: 新增公开API GrandPowers.CanDoActions(state)
      条件: state.total_influence >= 20 或 任意区域 control >= 50
```

#### 2.2 世界报告从"被动展示"到"主动推送"

当前世界报告是玩家主动点开才能看。改为：

- **每季结算后自动弹出"世界简报"**（1-3条重要事件）
- 事件来源：大国征服、主权变更、继承事件、玩家行动的连锁反应
- 格式举例："1914Q4：德意志帝国征服了低地国家。你作为战争供给商的收入将增加。"

**实现**：`GrandPowers.Tick()` 的返回值 `report` 已经包含了这些消息。只需在 UI 层添加一个结算后弹窗展示 `report.conquest_msgs` 和 `report.succession_msgs`，并附加与玩家相关的影响分析。

### 优化3：贸易系统——从"多步骤搬运工"到"路线经营"

**现状问题**：
- 一次完整贸易需要：接单(1AP) → 分配装备 → 发货(1AP)，共2AP + 多步操作
- 6AP/回合的预算下，做2单贸易就花掉4AP，几乎无法做其他事
- 和平期每季只生成1个订单，选择空间很小

**改动方案**：

#### 3.1 简化操作流程

**合并接单和发货为一步**：玩家选择订单后，系统自动检查库存、分配装备、扣除运费、开始运输。一次操作 = 1AP。

```lua
-- 新增 Trade.QuickFulfill(state, orderId, escortSquadId)
-- 合并 Accept + Allocate + Ship 为一步
-- AP 消耗从 2(accept+ship) 降为 1
-- 条件：库存满足 + 现金够运费
```

保留手动分步操作作为"高级模式"（但默认用一键完成）。

#### 3.2 增加和平期订单数

```
文件: scripts/data/balance.lua
改动:
  - peace_order_count: 1 → 3
  - 新增 peace_order_variety_bonus: 完成不同路线的订单额外+1
```

理由：和平期（Ch1、Ch3、Ch5）占游戏约一半时间，只有1个订单太少。增加到3个让玩家有选择余地。

#### 3.3 路线升级机制

新增**路线等级**概念：同一条路线完成订单越多，该路线的基础安全度和订单价格越高。

```lua
-- 路线等级数据（存在 state.trade.route_levels 中）
-- 每完成1单: +1 经验
-- 每5经验: 升1级（最高5级）
-- 每级效果: base_safety +0.03, payment_base ×1.05
```

这让贸易从"随机搬运"变成"经营路线"，玩家有长期投资感。

### 优化4：远征系统——从"打地鼠"到"战略征服"

**现状问题**：
- 突袭一个国家需要反复点击raid 8-10次才能把HP打到0
- 每次raid消耗2AP+200现金，但单次伤害只有30-200（总HP通常400-700）
- 这个过程感觉像无脑打地鼠

**改动方案**：

#### 4.1 引入"战线推进"替代逐次突袭

将突袭改为**开辟战线**机制：

```
当前: 每次raid = 1次伤害判定
优化: 开辟战线(2AP+500) → 建立持续压力 → 每季自动推进 → 关键节点决策
```

具体设计：

- **开辟战线**（新增 `Expedition.OpenFront`）：2AP + 500现金，对目标国家建立持续军事压力
- **战线推进**：每季结算时，活跃战线自动对目标造成伤害（基于玩家战力vs国家稳定性）
- **主动突击**（保留 `Raid` 但改名为 `Assault`）：1AP + 100现金，对已有战线的目标进行额外打击，加速推进
- **占领不变**：HP归零后仍需手动占领(3AP+500)

这样，征服一个弱国（minor）的流程变为：
```
回合N: 开辟战线(2AP) →
回合N+1: 自动推进(造成~100伤害) + 可选突击(1AP, ~80伤害)→
回合N+2: HP归零 → 占领(3AP)
```

总计约5-6AP + 3回合，但**玩家每回合只需要做1-2次决策**而非8-10次点击。

#### 4.2 战线维护费

每条活跃战线每季消耗维护费（150-300，取决于目标国家tier）。这创造了资源压力：开太多战线 = 烧钱快 = 迫使玩家做取舍。

#### 4.3 保留难度递增

现有的 `difficulty_tiers`（1.0x→1.15x→1.35x→1.60x）保留且与战线系统兼容。前进基地加成也保留。

### 优化5：系统耦合——从"平行线"到"反馈环"

**现状问题**：贸易和远征除了共享AP之外没有交互。大国外交对贸易/远征几乎没有实质影响。

**改动方案**：

#### 5.1 贸易→远征正循环

- **战时订单中新增"军事物资"类型**：完成后获得"军事物资储备"buff，使下一次远征行动伤害+15%
- **实现**：贸易完成时在 `state.expedition_buffs` 中写入 `{type="supply_boost", value=0.15, turns=2}`，远征伤害计算时读取

#### 5.2 远征→贸易正循环

- **占领国家自动开通新贸易路线**：占领成功后，该国成为新的贸易买家
- **实现**：`Expedition.Occupy()` 成功后调用 `TradeRoutesData.UnlockRouteForCountry(state, countryId)`

#### 5.3 大国外交→贸易/远征联动

| 外交行为 | 贸易影响 | 远征影响 |
|---------|---------|---------|
| 好感度 ≥ 30 | 该大国路线安全度+0.10 | 该大国控制区不可远征（保护） |
| 好感度 ≤ -30 | 该大国路线安全度-0.10 | 该大国控制区远征伤害+10% |
| 执行 war_supplier | 立即获得1个该大国的贸易订单 | — |
| 执行 support_guerrilla | — | 目标占领区抵抗+5，如果你也在远征该区则你的难度-10% |

**实现**：在各系统中添加对 `power.attitude_to_player` 和 `collaboration_score` 的读取。

### 优化6：信息呈现——从"数据墙"到"态势感知"

**现状问题**：
- 17个国家×3维度 = 51个数字需要跟踪
- 大国势力面板没有优先级排序，玩家不知道该关注谁
- 缺乏"与我相关"的信息过滤

**改动方案**：

#### 6.1 "聚光灯"模式

世界地图默认只高亮显示**与玩家有直接关系的国家**：
- 邻接国家（波斯尼亚直接邻接的3个）
- 正在贸易的国家
- 正在远征的国家
- 有外交互动的大国

其余国家灰显，点击后展开详情。

#### 6.2 大国面板简化

默认只显示 **"与我相关"** 的大国（有过外交互动、是贸易买家、是远征目标的宗主国），其余折叠。

每个大国卡片只显示3个核心信息：
```
[奥匈帝国]  军 65 | 经 68 | 厌 5
好感: +12 (偏向合作)  |  本季可做: 战争供给商、情报共享
```

#### 6.3 操作建议系统

在世界页底部添加 **"顾问建议"** 栏（1-2条），根据当前局势生成建议：

```
"奥匈帝国厌战度达到 55，正是发动货币战争的好时机"
"与纳粹德国的贸易路线安全度降至 45%，建议派编队护送或暂停该路线"
"你已对法兰西连续制裁3季，再坚持1季将触发[战争推迟]分支"
```

**实现**：纯UI层逻辑，在世界页渲染时根据 `state.powers`、`state.trade`、`state.expeditions` 的关键阈值生成文案。

## 五、风险评估

| 风险 | 描述 | 缓解措施 |
|------|------|---------|
| 漂移率过低 | 0.03可能导致玩家过度偏离历史线 | 设置硬限：偏离基准线超过±20时漂移率恢复到0.08 |
| 分层解锁太早 | 贸易在第16回合解锁可能让玩家收入过高 | 早期贸易订单金额较低（和平期基础报酬×0.6） |
| 战线系统复杂度 | 新增战线概念增加学习成本 | 首次开战前弹出教学引导 |
| 系统耦合过紧 | 贸易buff影响远征可能导致雪球效应 | buff有持续时间（2回合），且最多叠加1层 |

## 六、不改动的部分

以下现有设计经评估后认为合理，不建议改动：

- **征服时间线**（`CONQUEST_TIMELINE`）：历史事件的预编排是本游戏的核心叙事框架，玩家通过分支标记影响而非替代它
- **17个欧洲国家的数据结构**：只需改前端展示，不需要删减国家
- **AP系统基础值**（6+4）：AP紧张是策略游戏的核心张力，不应放松
- **称号系统结构**（19个称号×5类）：系统本身设计合理，只需调整幕后执政的独占门控角色
- **HP血条系统的核心公式**：伤害计算、大国双层HP、难度递增等数值设计是合理的
