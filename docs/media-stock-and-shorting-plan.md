# 媒体股票、文化事件与做空机制实施计划 (v3)

## 概述

针对"外交职员重要性不足"问题，新增三大互锁系统：**媒体股票** → **信息博弈事件** → **庄家操盘 + 做空机制**，形成"文化-金融"玩法闭环。v3 新增四个操盘反制机制（M1~M4），从机制层面约束操盘+做空组合的滥用。

### v3 核心变化（相比 v2）

1. **M1 媒体公信力**：操盘消耗公信力（初始 60/100），公信力越低成功率越低，形成自限机制。
2. **M2 操盘方向互斥**：Pump/Dump 成功后 3 季内不能反向操盘同一股票，但不限制普通买卖。
3. **M3 解耦新闻社**：做空利息折扣从新闻社迁移到奥匈银行信托，打破操盘+做空自耦合正反馈。
4. **M4 AI 对手盘**：外国资本在操盘成功后概率反制，注入反向 delta_mu 部分抵消效果。

### v2 核心变化（相比 v1）

1. **事件从"选择题"改为"信息博弈"**：事件只公布市场消息，玩家自行判断真假并操作。文化顾问满配（bonus >= 1.0）时揭示隐藏的真实走势时间表。
2. **庄家操盘行动**：在资产交易面板中新增"做多操盘"和"做空操盘"，需要资金体量门槛，玩家主动发起市场操控。
3. **外交总监 → 文化顾问**：信息优势的核心载体从外交总监调整为文化顾问（charisma + knowledge），更符合"媒体/情报"定位。外交总监仍提供 sector bonus 和操盘成本优惠。

## 二、信息博弈事件系统（v2 重新设计）

### 2.1 核心理念：消息公布 → 玩家判断 → 文化顾问揭秘

**与 v1 的根本区别**：

| v1 | v2 |
|----|-----|
| 事件弹窗提供 A/B/C 选项 | 事件只发布"市场消息"，无选项 |
| 选项直接决定结果 | 玩家根据消息自行去市场买/卖/做空/观望 |
| 外交总监解锁特殊选项 | 文化顾问满配时，消息中**额外显示隐藏情报** |

### 2.2 消息事件机制

#### 数据结构

```lua
-- 每个消息事件包含：
{
    id = "media_bull_forecast",
    title = "📰 新闻社利好预测",
    -- 玩家看到的公开消息
    public_message = "巴尔干新闻社头版报道：{stock_name}基本面利好，业内人士预计未来4个季度将持续上涨。",
    -- 文化顾问满配时看到的隐藏情报
    intel_message = "⚠ 顾问密报：消息源不可靠，实际利好仅持续约1个季度，之后庄家将集中出货。预计第2-4季度回落。",
    -- 文化顾问非满配但在任时看到的模糊提示
    hint_message = "💡 顾问提示：此消息可信度存疑，建议谨慎。",
    -- 实际市场效果（玩家看不到这些数值）
    actual_effects = {
        { stock_id = "{target}", delta_mu = 0.20, duration = 1 },   -- Q1 涨
        { stock_id = "{target}", delta_mu = -0.12, duration = 3 },  -- Q2-Q4 跌
    },
}
```

#### 文化顾问信息层级

| 文化顾问状态 | 玩家看到的信息 |
|-------------|--------------|
| **无文化顾问** | 只看到 `public_message`（公开消息） |
| **有文化顾问，bonus < 1.0** | 公开消息 + `hint_message`（模糊提示："此消息可信度存疑"） |
| **满配文化顾问，bonus >= 1.0** | 公开消息 + `intel_message`（**精确情报：实际涨跌季数**） |

> 这让文化顾问的价值非常直观：**满配 = 看穿市场骗局，精确知道真实走势**。

### 2.3 消息事件列表（5 个）

#### 事件 1：利好预测 (media_bull_forecast)
- **触发**：随机，需 `d3_newspaper` 已研究，12%/季，4 季冷却
- **公开消息**："{stock_name}基本面利好，预计未来4个季度将持续上涨。"
- **模糊提示**（顾问在任）："此消息可信度存疑，建议谨慎。"
- **精确情报**（满配顾问）："消息源不可靠，实际利好仅持续约1个季度，之后庄家将集中出货。"
- **实际**：目标股 +0.20 共 1 季 → -0.12 共 3 季
- **目标选择**：随机选择一只非新闻社股票

#### 事件 2：利空恐慌 (media_bear_panic)
- **触发**：随机，需 `d3_newspaper` 已研究，10%/季，4 季冷却
- **公开消息**："{stock_name}被曝管理层丑闻，多家机构下调评级，恐将持续下跌。"
- **模糊提示**："此报道有夸大嫌疑。"
- **精确情报**："报道系竞争对手授意，实际基本面未变。预计下跌1-2季后将反弹超越前高。"
- **实际**：目标股 -0.18 共 2 季 → +0.10 共 2 季
- **玩法**：没有情报的玩家恐慌抛售亏钱，有情报的玩家逆势抄底

#### 事件 3：行业景气报告 (media_sector_report)
- **触发**：随机，需 `d5_radio` 已研究，15%/季，5 季冷却
- **公开消息**："权威机构发布报告，{sector_name}行业未来将迎来黄金发展期，建议重仓配置。"
- **模糊提示**："报告作者与利益方有关联。"
- **精确情报**："该报告由{sector_name}行业协会赞助。实际利好有限，仅2季温和增长后回归正常。"
- **实际**：该板块所有股票 +0.08 共 2 季（温和上涨，非暴涨）
- **设计意图**：公开消息暗示"黄金发展期"让人以为会大涨很久，实际只是温和涨 2 季

#### 事件 4：政治内幕 (media_political_leak)
- **触发**：随机，需 `d4a` 或 `d4b` 已研究 + influence >= 50，8%/季，6 季冷却
- **公开消息**："据可靠消息，政府正在考虑对{stock_name}所在行业实施新的监管政策。市场观望情绪浓厚。"
- **模糊提示**："政策落地尚不确定。"
- **精确情报**："政策将在2个季度后实施，短期利空但长期利好（行业整合后龙头受益）。建议先减仓后回补。"
- **实际**：目标股 -0.10 共 2 季 → +0.15 共 2 季
- **玩法**：最优策略是先卖/做空 2 季，再买回

#### 事件 5：战时谣言 (media_war_rumor)
- **触发**：随机，需 `at_war = true`，20%/季，3 季冷却
- **公开消息**："前线传来消息，战事即将出现重大转折。军工股闻声大涨，航运股承压。"
- **模糊提示**："前线消息真假难辨。"
- **精确情报**："经核实此为虚假情报，军工股短暂上涨后将回落，航运实际影响有限。"
- **实际**：军工 +0.15 共 1 季 → -0.08 共 2 季；航运 -0.05 共 1 季（影响轻微）

## 三、庄家操盘行动（v2 新增）

### 3.1 核心理念

玩家在**资产交易面板**中主动发起市场操控，需要：
- 足够的资金体量（庄家门槛）
- 媒体股持股等级（舆论控制力）
- 对应科技解锁
- 操盘有成功率，受文化顾问 bonus 影响

### 3.2 操盘行动列表

#### 做多操盘 (market_pump)

| 项目 | 值 |
|------|-----|
| 入口 | 资产交易面板 → "做多操盘"按钮 |
| 消耗 | 1 AP + **目标股票当前市值 x 15%** 的现金（庄家资金投入） |
| 前置 | `d3_newspaper` 已研究 + 新闻社 >= stake |
| 最低资金门槛 | 40000 现金（不够则按钮置灰） |
| 效果 | 目标股票 delta_mu +0.15 共 2 季 |
| 成功率 | 基础 70%，文化顾问 bonus 每 0.1 加 5%（满配 = 100%失败时资金损失 50%，无市场效果） |
| 冷却 | 2 季 |
| 外交总监加成 | 在任时，资金投入降低 10%（人脉减少成本） |

#### 做空操盘 (market_dump)

| 项目 | 值 |
|------|-----|
| 入口 | 资产交易面板 → "做空操盘"按钮 |
| 消耗 | 1 AP + **目标股票当前市值 x 20%** 的现金（更高风险） |
| 前置 | `d5_radio` 已研究 + 新闻社 >= influence |
| 最低资金门槛 | 60000 现金（不够则按钮置灰） |
| 效果 | 目标股票 delta_mu -0.18 共 2 季，之后 +0.06 共 1 季（反弹） |
| 成功率 | 基础 60%，文化顾问 bonus 每 0.1 加 6%（满配 = 96%）失败时资金损失 60%，且目标股票反向上涨 +0.08 共 1 季 |
| 冷却 | 3 季 |
| 外交总监加成 | 在任时，资金投入降低 15%（人脉减少成本） |

#### 联合操盘 (market_coordinated) — 高阶

| 项目 | 值 |
|------|-----|
| 入口 | 资产交易面板 → "联合操盘"按钮 |
| 消耗 | 2 AP + 100000 现金（固定） |
| 前置 | `d7_wartime_media` 已研究 + 新闻社 >= control + 文化顾问 bonus >= 0.8 |
| 效果 | **同时**操控两只股票：一只 +0.20 共 2 季，一只 -0.15 共 2 季（玩家选择） |
| 成功率 | 基础 50%，满配顾问提升至 80%。失败：资金损失 70%，声誉 -5 |
| 冷却 | 5 季 |
| 设计意图 | 终极庄家操作：做多 A 的同时做空 B，配合做空仓位实现最大收益 |

### 3.3 操盘 UI 流程

```
资产交易面板
└─ "📊 市场操盘" 分组
   ├─ [做多操盘] 按钮（绿色）
   │   → 弹出股票选择器（7只股票列表，显示当前价格）

       → 执行
```

## 四、做空机制

> 与 v1 一致，以下仅列出关键变化。

### 4.1 解锁科技

新增 `b7_short_selling`（卖空交易）：requires `b6_stock_exchange`，cost 900，turns 5。

### 4.2 做空规则

| 规则 | 值 |
|------|-----|
| 最大做空股数 | max_shares x 30% |
| 保证金比例 | 50% |
| 每季利息 | 5%（按当前市值） |
| 强制平仓线 | 亏损 >= 保证金 x 80% |
| 最大持仓期 | 8 季 |

### 4.3 盈亏计算

```
浮动盈亏 = (entry_price - current_price) x shares
利息成本 = shares x current_price x 0.05 x seasons_held
实际盈亏 = 浮动盈亏 - 利息成本
平仓结算 = 归还保证金 + 实际盈亏
```

### 4.4 科技/顾问加成

| 条件 | 做空增益 |
|------|---------|
| diplomat bonus >= 0.5 | 利息降至 4% |
| `d5_radio` 已研究 | 最大做空提至 40% |
| `d7_wartime_media` 已研究 | 强平线放宽至 90% |
| 奥匈银行信托 >= influence | 利息降至 4%（M3 解耦） |
| 奥匈银行信托 >= control | 利息降至 3%（M3 解耦） |

> **M3 变更说明**：做空利息折扣原先绑定在巴尔干新闻社持股上，这导致新闻社同时加成操盘成功率和做空利息，形成自耦合正反馈。现已将利息折扣迁移到奥匈银行信托（`austro_bank_trust`），使操盘和做空的资源投入分散到不同资产。

### 4.5 修改文件

- `data/tech_data.lua` — 新增 `b7_short_selling`

## 五、玩法闭环总览

### 5.1 三层策略深度

```
第一层：信息获取（被动）
  消息事件发布市场新闻
    → 无顾问：只看到新闻，自行判断
    → 有顾问：模糊提示（"可信度存疑"）
    → 满配顾问：精确情报（"实际只涨1季，之后暴跌"）

第二层：市场操作（主动交易）
  根据信息做出交易决策
    → 买入 / 卖出（基础操作）
    → 做空开仓 / 平仓（需 b7 科技）

第三层：庄家操盘（主动操控）
  玩家主动制造市场波动
    → 做多操盘：投入资金拉升目标股票
    → 做空操盘：投入资金打压目标股票
    → 联合操盘：同时拉升A打压B（终极操作）
    → 配合自己的做空仓位实现最大收益
```

### 5.2 完整获利路径示例

```
1. 研究 b7_short_selling（解锁做空）
2. 研究 d5_radio + 新闻社持股至 influence
3. 安排满配文化顾问（charisma + knowledge 都高）
4. 等待消息事件 → 顾问揭示"实际只涨1季"
5. Q1：消息发布，市场上涨，玩家逆势开空仓
6. 同时发动"做空操盘"加速打压
7. Q2-Q4：股价下跌，空仓获利
8. 平仓，收割利润
```

### 5.3 角色分工

| 角色 | 在金融战中的作用 |
|------|----------------|
| **文化顾问**（charisma + knowledge） | **核心**：揭示市场消息真相，提升操盘成功率 |
| **外交总监**（charisma + strategy） | **辅助**：降低操盘资金成本，新闻社 sector bonus +0.15 |
| **科技顾问**（knowledge + ambition） | **前置**：加速研究 b7/d3/d5 等关键科技 |

## 七、操盘反制机制（M1~M4）

> **设计背景**：初版操盘 + 做空组合存在两个 S 级平衡性问题——Pump 操盘期望值过高（EV 显著为正）、新闻社控股同时加成操盘和做空利息形成自耦合正反馈。以下四个机制从**机制层面**（而非单纯调数值）进行约束。

### 7.1 M3: 解耦新闻社（做空利息折扣迁移）

**问题**：新闻社 control 同时提供"操盘成功率/成本加成"和"做空利息 3%"，使得同一资产投入带来双重收益，形成 Pump→做空→利息省→更多资金→更多 Pump 的正反馈循环。

**方案**：将做空利息折扣从巴尔干新闻社转移到奥匈银行信托（`austro_bank_trust`）。

| 条件 | 旧机制 | 新机制 |
|------|--------|--------|
| 新闻社 >= control | 做空利息降至 3% | ~~已移除~~ |
| 银行信托 >= influence | — | 做空利息降至 4% |
| 银行信托 >= control | — | 做空利息降至 3% |

**效果**：玩家要同时获得操盘能力和利息优惠，必须分散资金到两只股票，提高资源竞争压力。

### 7.2 M2: 操盘方向互斥锁

**问题**：玩家可以在同一只股票上快速交替 Pump→Dump（或反向），利用注入的 delta_mu 两头获利。

**方案**：Pump/Dump 成功后对**同一只股票**设置反向操盘冷却，但**不限制普通买卖和做空**。

| 触发 | 效果 | 持续 |
|------|------|------|
| Pump 成功 | 该股 3 季内不能 Dump（包括联合操盘中的 Dump 目标） | 3 季 |
| Dump 成功 | 该股 3 季内不能 Pump（包括联合操盘中的 Pump 目标） | 3 季 |

**关键设计**：
- 只锁操盘（`no_pump` / `no_dump`），**不锁**普通 Buy/Sell/OpenShort/CloseShort
- 联合操盘的两个目标分别检查和设锁
- 每季自动递减，到 0 解除

### 7.3 M1: 媒体公信力（消耗性资源）

**问题**：只要资金够，玩家可以无限制反复操盘。

**方案**：引入"媒体公信力"（0~100），每次操盘消耗公信力，公信力越低操盘成功率越低。

#### 参数

| 项目 | 值 |
|------|-----|
| 初始值 | **60**（非满值，开局就有压力） |
| 上限 | 100 |
| Pump 成功消耗 | 15 |
| Dump 成功消耗 | 20 |
| 联合操盘成功消耗 | 30 |
| 失败消耗倍率 | ×1.5（失败比成功消耗更多） |
| 每季自然恢复 | +5 |
| 新闻社 control 额外恢复 | +3/季 |
| 新闻社 influence 额外恢复 | +1/季 |

#### 对成功率的影响

```
credibilityMultiplier = 0.5 + 0.5 × (credibility / 100)

实际成功率 = base_success × credibilityMultiplier
```

| 公信力 | 乘数 | Pump 实际成功率 | Dump 实际成功率 |
|--------|------|----------------|----------------|
| 100 | ×1.00 | 70% | 60% |
| 60（初始） | ×0.80 | 56% | 48% |
| 30 | ×0.65 | 45.5% | 39% |
| 0 | ×0.50 | 35% | 30% |

**新闻社的新定位**：不再直接增益操盘成功率，而是**加速公信力恢复**——控股新闻社的玩家能更快"回血"，但单次操盘不会更强。

### 7.4 M4: AI 对手盘反制

**问题**：市场中无对手方力量，玩家单向操纵无阻力。

**方案**：外国资本（`foreign_capital`）AI 在玩家操盘成功后有概率发起反向交易，部分抵消操盘效果。

#### 触发条件

1. 存在未被击败的外国资本势力
2. 外资现金 >= 3000

#### 概率计算

```
finalChance = baseChance × cashScale × (2.0 - credibilityMultiplier)
```

| 操盘类型 | 基础概率 | 反向 delta_mu | 持续 |
|---------|---------|--------------|------|
| Pump | 30% | -0.06 | 2 季 |
| Dump | 25% | +0.05 | 2 季 |
| 联合操盘 | 45%（两目标分别判定） | 对应方向 | 2 季 |

#### 概率修正因子

| 因子 | 公式 | 说明 |
|------|------|------|
| 现金规模 | `clamp(cash / 5000, 0.2, min(cash/5000, cash_scale_max系数))` | 外资越富越积极 |
| 公信力联动 | `×(2.0 - credMult)` | 玩家公信力越低（操盘越频繁），AI 越容易识破 |

- 反制消耗外资现金的 5%（非免费行为）
- 反制成功后写入日志，玩家可见

#### 设计意图

- 操盘不再是"投入→确定收益"，而是"投入→可能被对冲"
- 联合操盘的 45% 基础反制率远高于单独操盘，体现高风险
- 与 M1 形成联动：公信力低 → AI 反制概率高 → 形成负反馈闭环

### 7.5 四个机制协同关系

```
玩家发起操盘
  │
  ├─ M2 方向锁检查 ──→ 被锁则直接拒绝
  │
  ├─ M1 公信力 ──→ 降低成功率
  │    │
  │    └─ 成功/失败都消耗公信力
  │
  ├─ 成功后 ──→ M4 AI 对手盘概率反制
  │    │          │
  │    │          └─ 公信力越低，反制概率越高
  │    │
  │    └─ M2 设置方向锁（禁止反向操盘 3 季）
  │
  └─ M3 做空利息 ──→ 需要投资银行信托（分散资源）
```

## 八、平衡性考量

| 风险 | 缓解措施 |
|------|---------|
| 操盘+做空无风险套利 | M1 公信力消耗 + M4 AI 反制 + 操盘失败损失 50-70%；做空有 5% 季利息 + 保证金冻结 |
| Pump→Dump 快速方向切换 | M2 方向锁：Pump 后 3 季不能 Dump 同一股，反之亦然 |
| 新闻社一股通吃 | M3 做空利息折扣移至银行信托，操盘/做空需分散资源 |
| 无限制反复操盘 | M1 公信力（初始 60/100），连续操盘成功率骤降至 35~50% |
| 操盘无对手方阻力 | M4 外资 AI 反制，注入反向 delta_mu 部分抵消效果 |
| 满配顾问 = 必赢 | 消息事件是随机触发的，玩家不能控制何时出现；精确情报只说"约1季"不说具体数值 |
| 资金门槛太低 | 做多操盘需 40000+，做空操盘需 60000+，联合操盘固定 100000，中前期用不起 |
| 媒体股影响力暴涨 | 控股最多 +4/季，自然衰减 -1/季，净增长有限 |
| 做空亏损无底 | 强平线 80% + 8 季上限 + 保证金冻结 |
| 联合操盘太强 | 需 d7 + 新闻社 control + 顾问 0.8+；失败率高（基础50%）+ M4 反制概率 45% |
