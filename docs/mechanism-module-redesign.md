# 游戏机制指标重构与模块分配方案

> 目标：不删除现有系统，而是重新定义指标层级和模块归属，让玩家知道“这个数值是什么、在哪里看、用来做什么、会影响哪些决策”。

## 1. 总体原则

当前游戏的问题不是机制数量过多，而是多个指标承担了相近含义，导致玩家难以判断优先级。

新的设计原则：

- 主界面只展示本回合必须扫一眼的核心指标。
- 页面模块只展示与该模块决策直接相关的指标。
- 派生指标只展示结果和主要原因，不作为玩家反复堆叠的基础资源。
- 子系统材料留在对应系统里，不进入全局主资源。
- 同一词不要跨系统复用，尤其避免“影响力”“声誉”“士气”这类含义漂移的词。

## 2. 指标总分层

### 2.1 主界面核心指标

这些指标应常驻顶部或 Dashboard 首屏。

| 指标 | 定位 | 主要用途 | 不应承担的内容 |
| --- | --- | --- | --- |
| 现金 | 短期支付能力 | 工资、维护、行动、投资、贷款压力 | 不代表长期实力 |
| 黄金 | 长期保值资产 | 抗通胀、紧急变现、经济胜利 | 不与铜煤同级展示 |
| AP | 本季行动预算 | 限制每季行动数量 | 不混入长期成长 |
| 武力 | 军事综合实力 | 战斗、压制、秩序、防御 | 不只等于护卫数量 |
| 地区控制 | 实际统治范围 | 地区收益、胜利、秩序基础 | 不等于民心或治安 |
| 政治资本 | 可消费软实力 | 渗透、协议、外交、宣传 | 不等于地区长期民心 |

### 2.2 路线指标

这些指标用于说明玩家当前路线进度，适合放在 Dashboard 的路线卡、结算摘要或胜利页面。

| 指标 | 所属路线 | 用途 |
| --- | --- | --- |
| 经营实力 | 经营路线 | 汇总净资产、矿业产能、现金流、股票资产 |
| 军事威慑 | 军事路线 | 汇总武力、装备、胜场、战意、控制区 |
| 政治影响 | 政治路线 | 汇总政治资本、地区民心、外交关系、控制区 |
| 恶名 | 掠夺路线 | 表示掠夺代价、交易惩罚、AI 攻击风险 |

### 2.3 派生态势

这些指标不建议作为主资源，而是作为风险提示或诊断结果。

| 指标 | 来源 | 展示方式 |
| --- | --- | --- |
| 秩序 | 地区控制、武力、AI 存在、恶名 | 世界页和 Dashboard 风险提示 |
| 净资产 | 现金、商品、矿山、股票、负债 | 市场/贷款页，Dashboard 可摘要 |
| 通胀 | 年代、战争、事件、市场环境 | 市场页和结算摘要 |
| AI 威胁 | AI 势力、态度、地区存在、战力 | 世界页和军事页 |
| 现金流 | 本季收入 - 本季支出 | 产业页和结算摘要 |

### 2.4 子系统材料

这些内容保留，但不放到主界面核心资源组。

| 指标 | 所属模块 | 用途 |
| --- | --- | --- |
| 铜 | 产业 / 军工 | 装备生产、维护减免、商品交易 |
| 煤 | 产业 / 军工 | 工业动力、兵工厂消耗、商品交易 |
| 工人 | 产业 | 产能、工资成本 |
| 劳工满意度 | 产业 | 罢工风险、效率、工资压力 |
| 补给 | 军事 | 维持战斗力和驻军消耗 |
| 战意 | 军事 | 影响武力和战斗结果 |
| 装备 | 军事 | 提升武力和军事胜利 |
| 媒体公信力 | 市场 / 操盘 | 限制股市操盘频率和成功率 |
| 大国态度 | 外交 / 大国 | 决定合作、冲突、占领关系 |
| 合作度 | 外交 / 大国 | 决定与占领方或大国的特殊行动 |

## 3. 模块分配方案

## 3.1 主界面 / 顶栏

主界面只解决一个问题：玩家进入回合时，能否快速判断当前局势。

### 应展示

- 现金
- 黄金
- AP
- 武力
- 地区控制
- 政治资本
- 当前年份 / 季度
- 1 条最重要风险提示，例如“现金流为负”“秩序恶化”“贷款临近违约”

### 不应展示

- 铜
- 煤
- 净资产详细值
- 产金预估
- 商品市值
- 单个地区影响力
- 媒体公信力
- 工人士气
- 军队士气

### 建议呈现

主界面指标可以分两组：

- 资源组：现金、黄金、AP。
- 权力组：武力、地区控制、政治资本。

这样玩家会自然理解：前者决定“能不能做事”，后者决定“做事有没有结果”。

## 3.2 Dashboard / 回合总览

Dashboard 不应成为所有信息的堆叠页，而应是回合决策页。

### 应展示

- 本季推荐关注事项。
- 三条路线状态：经营、军事、政治。
- 当前最大风险：破产、秩序、战争、恶名、通胀。
- 快速行动入口：投资、招募、渗透、交易、结束回合。
- 本季现金流摘要。

### 指标归属

| 内容 | 放置方式 |
| --- | --- |
| 现金流 | 作为本季概览的第一项 |
| 秩序 | 只显示总体等级和恶化原因 |
| 净资产 | 只在贷款风险较高时提示 |
| 通胀 | 战时或快速上升时提示 |
| 恶名 | 只在达到惩罚档位时提示 |
| 路线进度 | 用三张路线卡展示 |

### 不建议

- 不要在 Dashboard 展示铜煤库存明细。
- 不要展示每个地区的完整数值。
- 不要把市场行情放在首屏，除非有暴涨暴跌事件。

## 3.3 产业模块

产业模块负责解释“钱和物资从哪里来，成本在哪里”。

### 应展示

- 矿山列表。
- 黄金产量和储量。
- 铜库存、铜产量、铜用途。
- 煤库存、煤产量、煤炭分配。
- 工人数量。
- 工资。
- 劳工满意度。
- 本季收入、支出、净现金流。
- 通胀对工资和维护的影响。

### 指标归属

| 内容 | 模块定位 |
| --- | --- |
| 黄金产量 | 矿山卡核心信息 |
| 黄金库存 | 可显示，但弱于主界面 |
| 铜 | 军工材料和商品，不做主资源 |
| 煤 | 工业燃料和商品，不做主资源 |
| 工人 | 产能杠杆 |
| 劳工满意度 | 人力风险 |
| 通胀 | 成本环境 |
| 现金流 | 产业页核心结果 |

### 关键改法

- “工人士气”改名为“劳工满意度”。
- “产金”改成“本季预计产金”或“矿山预计产出”。
- “潜在售金”改成“采矿折算收入”，避免玩家误以为已经到账。
- 铜煤默认放在产业页明细，不进主界面。

## 3.4 军事模块

军事模块负责解释“能不能打，能不能守，能不能压住地方”。

### 应展示

- 武力综合值。
- 护卫数量。
- 编队。
- 装备等级。
- 补给。
- 战意。
- 近期胜败。
- 可攻击目标。
- AI 威胁。
- 武力对秩序的贡献。

### 指标归属

| 内容 | 模块定位 |
| --- | --- |
| 武力 | 军事模块主指标，也可上主界面 |
| 护卫 | 武力组成部分 |
| 装备 | 武力成长线 |
| 补给 | 武力维持成本 |
| 战意 | 影响战斗乘数 |
| 胜场 | 军事路线进度 |
| AI 威胁 | 战斗压力 |

### 关键改法

- “军队士气”改名为“战意”。
- 主界面不要只显示护卫数量，而显示“武力”。
- 护卫、装备、补给、战意都作为武力拆解项显示。
- 军事模块中明确告诉玩家：武力不仅用于战斗，也会影响地区秩序。

## 3.5 世界 / 地区模块

世界模块负责解释“谁控制哪里，哪里稳不稳，哪里值得扩张”。

### 应展示

- 每个地区的控制度。
- 每个地区的地区民心。
- 每个地区的秩序。
- AI 存在度。
- 地区类型：矿区、工业区、首都、港口、边境等。
- 地区资源。
- 渗透、投资、镇压等行动入口。

### 指标归属

| 内容 | 模块定位 |
| --- | --- |
| 地区控制 | 世界模块主指标，也可上主界面 |
| 地区民心 | 长期软控制，不直接消费 |
| 政治资本 | 执行渗透等行动的消耗池 |
| 秩序 | 地区稳定结果 |
| AI 存在 | 地区竞争压力 |
| 地区资源 | 决定扩张价值 |

### 关键改法

- 当前“影响力”拆成“地区民心”和“政治资本”。
- 地区卡上显示“民心”，不要显示“可花费影响力”。
- 渗透行动消耗“政治资本”，提升“地区控制”和少量“地区民心”。
- 秩序显示为结果，并列出主要原因，例如“AI 存在高”“武力不足”“恶名过高”。

## 3.6 市场 / 金融模块

市场模块负责解释“资产如何增值，债务风险在哪里，商品如何变现”。

### 应展示

- 股票列表。
- 持仓。
- 现金。
- 净资产。
- 总负债。
- 杠杆率。
- 通胀。
- 商品价格：黄金、铜、煤。
- 自动出售开关。
- 媒体公信力。
- 做多、做空、操盘行动。

### 指标归属

| 内容 | 模块定位 |
| --- | --- |
| 净资产 | 贷款和金融健康主指标 |
| 通胀 | 市场环境 |
| 黄金价格 | 资产价格 |
| 铜煤价格 | 商品交易价格 |
| 杠杆率 | 贷款风险 |
| 媒体公信力 | 操盘资源 |

### 关键改法

- “商品总市值”改成“库存商品市值”，避免和净资产混淆。
- 媒体公信力只在操盘区域出现。
- 市场页可以展示铜煤价格，但不要让铜煤成为全局主资源。
- 贷款风险应比股票细节更优先展示。

## 3.7 外交 / 大国模块

外交模块负责解释“外部势力怎么看你，战争和占领如何影响家族”。

### 应展示

- 大国态度。
- 合作度。
- 大国军事压力。
- 占领状态。
- 战争疲劳。
- 可执行外交行动。
- 外交行动对现金、政治资本、恶名、控制的影响。

### 指标归属

| 内容 | 模块定位 |
| --- | --- |
| 大国态度 | 外交关系 |
| 合作度 | 与占领方或大国合作程度 |
| 政治资本 | 外交行动消耗 |
| 恶名 | 影响外交可信度 |
| 战争状态 | 通胀、市场、军事压力来源 |

### 关键改法

- 大国态度不要和地区民心混在一起。
- 合作度不要上主界面，只在大国模块展示。
- 外交行动统一消耗“政治资本”或现金，避免继续扩展新的软实力货币。

## 3.8 掠夺模块

掠夺模块负责解释“高风险高收益路线的收益和代价”。

### 应展示

- 恶名。
- 当前恶名档位。
- 掠夺收益。
- 成功率。
- 失败惩罚。
- 交易惩罚。
- AI 攻击风险。
- 地区控制衰减风险。

### 指标归属

| 内容 | 模块定位 |
| --- | --- |
| 恶名 | 掠夺路线核心代价 |
| 掠夺收益 | 短期现金或资源 |
| AI 攻击风险 | 恶名后果 |
| 交易惩罚 | 恶名后果 |
| 控制衰减 | 高恶名后果 |

### 关键改法

- “声誉”整体改成“恶名”。
- 数值建议从 `0` 到 `100` 表达，越高越危险。
- 如果底层仍保留负数，可以 UI 显示为 `恶名 = -声誉`。
- 掠夺页应明确告诉玩家：掠夺是绕过经营成长的捷径，但会破坏秩序和外交环境。

## 3.9 家族模块

家族模块负责解释“核心成员如何改变各系统效率”。

### 应展示

- 家族成员。
- 成员属性。
- 岗位。
- 岗位适配度。
- 当前岗位加成。
- 空缺惩罚。
- 培养进度。

### 指标归属

| 内容 | 模块定位 |
| --- | --- |
| 成员属性 | 长期成长 |
| 岗位 | 系统加成入口 |
| 适配度 | 决定加成强弱 |
| 空缺惩罚 | 运营风险 |

### 关键改法

- 家族属性不要进入主界面。
- 家族加成应在对应模块显示结果，例如产业页显示“工业主管加成”，军事页显示“军事主管加成”。
- 不需要新增“家族声望”这类全局指标，避免再次增加概念。

## 3.10 科技模块

科技模块负责解释“长期解锁和路线强化”。

### 应展示

- 已研究科技。
- 研发中科技。
- 研发成本。
- 研发周期。
- 科技所属路线：经营、军事、政治、市场。
- 科技影响的指标。

### 指标归属

| 内容 | 模块定位 |
| --- | --- |
| 研发进度 | 科技页核心 |
| 科技路线 | 长期方向选择 |
| 政治资本 | 可作为部分科技/宣传相关消耗 |
| 现金 | 通用研发成本 |

### 关键改法

- 科技说明必须明确影响哪个主指标或哪个模块。
- 不要出现只写“影响力提升”但不说明是“地区民心”还是“政治资本”的文案。
- 科技树可以作为三路线强化器：经营增产、军事增武力、政治增民心/资本。

## 3.11 结算模块

结算模块负责解释“这一季发生了什么，为什么数值变化”。

### 应展示

- 收入来源。
- 支出来源。
- 净现金流。
- 黄金变化。
- 铜煤变化。
- 工资和维护。
- 贷款利息。
- 通胀影响。
- 秩序变化。
- 恶名恢复或恶化。
- 路线进度变化。

### 指标归属

| 内容 | 模块定位 |
| --- | --- |
| 净现金流 | 结算核心结果 |
| 通胀影响 | 成本解释 |
| 秩序变化 | 地区压力解释 |
| 恶名变化 | 掠夺后果解释 |
| 胜利进度 | 路线反馈 |

### 关键改法

- 结算摘要不要只报最终数值，要解释变化原因。
- 最重要的三条变化放在顶部，例如“现金 -320”“秩序下降”“军事进度 +12”。
- 铜煤明细可以折叠。

## 5. 命名规范

### 推荐保留

- 现金
- 黄金
- AP
- 武力
- 地区控制
- 政治资本
- 地区民心
- 秩序
- 恶名
- 战意
- 劳工满意度

### 建议避免

- 声望：容易和声誉、影响力、称号混淆。
- 声誉：当前机制是负面掠夺代价，不适合叫声誉。
- 影响力：含义太宽，除非明确前缀，例如“地区影响力”“股票影响力”。
- 士气：同时用于工人和军队，建议拆成劳工满意度和战意。
- 安全：容易和治安、秩序、军事防御混淆。

## 6. 优先级

### 第一优先级：立刻能降低混乱

1. 主界面只保留现金、黄金、AP、武力、地区控制、政治资本。
2. 声誉改名为恶名。
3. 工人士气改名为劳工满意度。
4. 军队士气改名为战意。
5. 治安改名为秩序，并标注为派生结果。

### 第二优先级：让机制逻辑更清晰

1. 影响力拆成地区民心和政治资本。
2. 武力成为军事主指标，护卫数量降为组成项。
3. 秩序显示变化原因。
4. Dashboard 增加三路线状态卡。
5. 结算摘要显示本季关键变化原因。

### 第三优先级：后续深改

1. 将政治资本从地区民心中独立出来。
2. 重做胜利评分，使经营、军事、政治三线更清楚。
3. 将铜煤彻底定位为产业材料，而不是主资源。
4. 将外交、大国、占领系统统一纳入政治路线。

## 7. 最终玩家心智模型

玩家应该这样理解游戏：

- 我用现金和黄金维持家族生存。
- 我用 AP 决定每季能做多少事。
- 我用产业创造财富。
- 我用武力保护地盘、压制敌人。
- 我用地区控制扩大统治。
- 我用政治资本改变局势。
- 我可以通过掠夺快速获利，但恶名会让秩序、外交和交易环境恶化。

最终目标不是减少玩法，而是让每个玩法都有自己的位置。
