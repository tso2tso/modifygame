### 1.2 阅读指南

- **`requires`**：前置科技，用 `,` 表示 AND（同时需要），用 `|` 表示 OR（任一即可）
  - 例：`"a7,c2"` = 需要同时完成 a7 和 c2
  - 例：`"c8a|c8b"` = 完成 c8a 或 c8b 其一即可
- **`excludes`**：互斥科技，研发此项后另一项永久锁定
- **`cost`**：研发所需科技点
- **`turns`**：研发所需季度数

### 1.3 效果类型速查

| 效果 kind | 说明 | 典型值 |
|-----------|------|--------|
| `mine_output_base` | 矿山基础产出（加法） | +1 ~ +4 |
| `mine_output_mult` | 矿山产出乘数（百分比加法） | +8% ~ +20% |
| `mine_slots` | 矿山槽位 | +2 |
| `worker_efficiency` | 工人效率乘数 | +5% ~ +12% |
| `accident_reduction` | 事故概率增减 | -15% ~ +5% |

| `security_bonus` | 矿区安全等级 | +1 |

| `equipment_up` | 装备等级 | +1 |

## 六、跨线依赖关系图

以下科技需要多条线路的前置（AND 依赖，用 `+` 表示）：

```
a8_raid_tactics        ← a7 (A线) + c2 (C线)
a10_guerrilla_logistics ← a9 (A线) + c5 (C线)
b11_trade_monopoly     ← b8 (B线) + c6a|c6b (C线)
c10_total_war          ← c9 (C线) + d7 (D线)
d9_secret_society      ← d8 (D线) + b8 (B线)
```

**设计意图**：跨线科技鼓励玩家多路线发展，纯单线玩家无法触及最强终极科技。掠夺向玩家尤其需要同时推进 A/C 双线。

## 八、随机事件系统

### 8.1 触发条件说明

| 条件字段 | 类型 | 说明 |
|---------|------|------|
| `requires_mine` | bool | 需要至少一座活跃矿山 |
| `min_year` | int | 最低年份（含） |
| `max_year` | int | 最高年份（含） |
| `min_workers` | int | 最低雇用工人数 |
| `max_security` | int | 最高治安等级 |
| `min_development` | int | 最低基建等级 |
| `requires_war` | bool | 需要处于战争状态 |
| `cooldown` | int | 触发后冷却季度数 |
| `min_reputation` | int | 声誉 ≤ 该值才触发（负数越小越极端） |
| `has_seized_veins` | bool | 需要已执行过矿脉强占行动 |
| `min_guards` | int | 最低护卫数量 |
| `min_influence` | int | 最低影响力值 |

### 8.5 媒体/市场情报事件（5 个）

这些事件由巴尔干新闻社（`balkan_press` 股票）机制驱动。与普通事件不同，它们**无玩家选项**，触发后自动产生股市效果。玩家通过文化顾问获取不同深度的信息：

- **无顾问**：只看到公开消息（可能误导）
- **有文化顾问（普通适配）**：获得提示信息
