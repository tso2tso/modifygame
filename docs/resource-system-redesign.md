# 资源系统重设计方案 v1.0

## 一、设计理念

当前三种资源（黄金、白银、煤炭）在机制上高度同质化——都是"挖出来 → 卖掉换现金"，缺乏策略性差异。重设计后：

| 资源 | 定位 | 核心动词 | 玩家抉择 |
|------|------|---------|---------|
| **黄金** | 抗通胀 / 储值 | **囤 vs 卖** | 通胀高时黄金升值，卖了换现金短期充裕但失去对冲 |
| **煤炭** | 动力燃料 | **烧 vs 卖** | 喂给兵工厂/矿山提升效率，还是卖掉换现金 |
| **铜** (原白银) | 工业原料 | **用 vs 卖** | 留着生产装备降成本，还是卖掉赚外汇 |

**核心设计目标**：每种资源都有"自用"和"出售"两个用途，玩家需要在二者间做取舍。

### 2.2 黄金 — 抗通胀机制（增强现有系统）

**现状**：黄金可以手动卖出换现金，有10%保留机制，金价受通胀浮动，胜利条件计入黄金量。

**新增机制**：

| 机制 | 设计 | 实现位置 |
|------|------|---------|
| **通胀对冲被动效果** | 每持有 10 黄金 → 所有支出的通胀乘数降低 2%（上限 -20%） | `economy.lua` → Settle() 支出计算处 |
| **金价与通胀联动** | 金价公式改为 `base_price × inflation^1.2`（超线性增长，通胀越高黄金越值钱） | `economy.lua` → 金价计算处 |
| **黄金储备利息** | 每季末对黄金储备 >20 的部分，按 0.5% 生息（折算现金，模拟金本位时代的储备收益） | `economy.lua` → Settle() 新增步骤 |
| **战时黄金溢价** | 战争期间金价额外 +30%（恐慌性购买） | `economy.lua` → 金价修正 |

**Balance 新增**：
```lua
Balance.GOLD = {
    inflation_hedge_per_10  = 0.02,  -- 每10黄金减少支出通胀2%
    inflation_hedge_cap     = 0.20,  -- 最多减少20%
    price_inflation_exponent = 1.2,  -- 金价 = base × inflation^1.2
    reserve_interest_threshold = 20, -- 超过20的部分生息
    reserve_interest_rate   = 0.005, -- 0.5%/季
    war_premium             = 0.30,  -- 战时溢价30%
}
```

**玩家抉择**：
- 囤黄金 → 对冲通胀（尤其战时通胀12%/季时极有价值），但损失流动性
- 卖黄金 → 即时现金，但失去被动保护
- 经济胜利需要黄金存量 → 和"卖掉换现金发展"形成张力

### 2.3 煤炭 — 发电 / 动力机制（全新系统）

**现状**：煤炭从工业区采出 → 全量自动出售换现金，无自用途径。

**新增机制**：煤炭成为兵工厂和矿山的**动力燃料**。

| 机制 | 设计 | 数值 |
|------|------|------|
| **兵工厂燃煤** | 兵工厂每季消耗煤炭才能运作；无煤则生产暂停 | Lv1: 3/季, Lv2: 5/季, Lv3: 8/季 |
| **矿山电力加成** | 玩家可选择分配煤炭给矿山，每投入 5 煤 → 金矿产出 +15%（上限 +30%） | 通过"电力分配"行动 |
| **煤炭出售改为手动** | 不再自动全量出售，玩家自行决定留多少、卖多少 | 类似黄金的手动出售模式 |
| **煤价与军需联动** | 战时煤价 +50%（军需品价格飞涨） | 新增修正器 |

**Balance 新增**：
```lua
Balance.COAL = {
    factory_consumption = { 3, 5, 8 },  -- 兵工厂各级每季煤耗
    mine_power_per_5    = 0.15,          -- 每5煤投入矿山+15%产出
    mine_power_cap      = 0.30,          -- 矿山电力加成上限30%
    war_price_premium   = 0.50,          -- 战时煤价+50%
}
```

**实现要点**：
- `equipment.lua` → `TickProduction()` 开头检查煤炭库存 ≥ 当级消耗量，不足则跳过本季生产（返回 "燃煤不足，生产暂停" 消息）
- `economy.lua` → `Settle()` 中兵工厂煤耗在收入计算后、支出计算前扣除 `state.coal`
- `game_state.lua` → 新增 `state.coal_allocation = { factory = true, mines = 0 }` 控制煤炭分配
- UI → 产业页新增"电力分配"面板，展示煤炭库存和分配状态

**玩家抉择**：
- 煤炭喂工厂 → 才能生产武器，军事发展必需
- 煤炭喂矿山 → 增加金矿产出，经济发展加速
- 煤炭出售 → 直接换现金（尤其战时煤价高时）
- 三者相互竞争同一煤炭池，形成资源三角

### 2.4 铜 — 工业制造机制（全新系统）

**现状**（白银）：矿山副产品 → 自动全量出售，纯被动收入。

**新增机制**：铜成为装备生产的**原材料**。

| 机制 | 设计 | 数值 |
|------|------|------|
| **装备生产需铜** | 每件装备生产除现金外，额外消耗铜 | T2: 3铜, T3: 6铜, T4: 10铜, T5: 15铜, T6: 25铜 |
| **铜储备降低维护费** | 每持有 10 铜 → 装备维护费 -5%（上限 -25%，模拟备件充足） | `equipment.lua` → 维护费计算 |
| **铜出售改为手动** | 不再自动全量出售，玩家决定留存/出售比例 | 类似黄金手动模式 |
| **外国矿铜矿** | 外国矿产出铜的价值提升（工业国更需要进口铜） | 提升外国铜矿产出系数 |

**Balance 新增**：
```lua
Balance.COPPER = {
    -- 装备生产铜耗（按 tier）
    prod_copper_cost = {
        rifle = 0,             -- T1 免费
        improved_rifle = 3,    -- T2
        mg = 6,                -- T3
        mortar = 10,           -- T4
        motorized = 15,        -- T5
        elite_kit = 25,        -- T6
    },
    maintenance_reduction_per_10 = 0.05,  -- 每10铜减维护费5%
    maintenance_reduction_cap    = 0.25,  -- 上限25%
}
```

**实现要点**：
- `equipment.lua` → `StartProduction()` / `StartOutsource()` 新增铜检查：`state.copper >= copper_cost`，不足则 return false
- `equipment.lua` → `CalcMaintenanceCost()` 根据 `state.copper` 应用维护费折扣
- `economy.lua` → 铜不再自动出售，改为类似黄金的手动出售（加入 `state.copper_auto_sell` 开关）
- UI → 产业页装备生产界面展示铜需求；市场页展示铜价和出售操作

**玩家抉择**：
- 留铜 → 生产装备（军事发展必需） + 降低维护费
- 卖铜 → 即时现金收入
- 外国铜矿 → 战略价值凸显（不仅是副收入，更是工业原料来源）

## 三、系统联动总览

```
                    ┌──────────┐
                    │   煤 炭   │
                    │ (动力燃料) │
                    └─────┬────┘
                          │
               ┌──────────┼──────────┐
               ▼          ▼          ▼
          ┌────────┐ ┌────────┐ ┌────────┐
          │兵工厂  │ │ 矿 山  │ │ 市 场  │
          │(必须)  │ │(可选+)  │ │(出售)  │
          └───┬────┘ └───┬────┘ └────────┘
              │          │
              ▼          ▼
         ┌────────┐ ┌────────┐
         │装备生产│ │金矿产出│
         └───┬────┘ └───┬────┘
             │          │
    ┌────────┤          │
    ▼        ▼          ▼
┌──────┐ ┌──────┐ ┌──────────┐
│ 铜   │ │ 现金 │ │  黄 金   │
│(原料)│ │      │ │(抗通胀)  │
└──┬───┘ └──────┘ └────┬─────┘
   │                    │
   ▼                    ▼
装备制造成本        通胀对冲 +
  + 维护减免         金价升值 +
                    储备生息
```

**关键联动点**：
1. **煤炭 ↔ 兵工厂**：无煤 = 无生产，军事线必须保障煤炭供应
2. **煤炭 ↔ 矿山**：投入煤炭 → 金矿增产 → 更多黄金 → 更强通胀对冲
3. **铜 ↔ 兵工厂**：无铜 = 无法生产高级装备，即使有现金和煤也不行
4. **黄金 ↔ 通胀**：囤金减少支出压力，但损失流动性
5. **三角抉择**：煤炭在"工厂/矿山/出售"间分配；铜在"生产/维护/出售"间分配；黄金在"储备/出售"间取舍

## 四、影响的事件系统

现有事件中引用 `silver_price_mod` 的地方统一改为 `copper_price_mod`。新增以下事件修正器：

| 修正器 | 效果 | 触发场景 |
|--------|------|---------|
| `coal_price_mod` | 煤价浮动 | 已存在，保持不变 |
| `copper_price_mod` | 铜价浮动 | 替代 `silver_price_mod` |
| `coal_consumption_mod` | 兵工厂/矿山煤耗修正 | 科技"高效锅炉"等 |
| `copper_efficiency_mod` | 装备铜耗修正 | 科技"精密铸造"等 |

## 五、存档兼容

`save_load.lua` 中添加迁移逻辑：
```lua
-- 旧存档兼容：silver → copper
if state.silver and not state.copper then
    state.copper = state.silver
    state.silver = nil
end
-- region 资源字段迁移
for _, r in ipairs(state.regions) do
    if r.resources.silver_reserve and not r.resources.copper_reserve then
        r.resources.copper_reserve = r.resources.silver_reserve
        r.resources.silver_reserve = nil
    end
end
```

## 六、实施步骤

1. **Phase 1 — 重命名**：白银 → 铜（全局替换，确保编译通过）
2. **Phase 2 — 黄金增强**：添加通胀对冲、金价超线性、储备生息
3. **Phase 3 — 煤炭动力化**：兵工厂煤耗、矿山电力加成、手动出售
4. **Phase 4 — 铜工业化**：装备铜耗、维护减免、手动出售
5. **Phase 5 — UI 更新**：产业页电力分配面板、装备铜耗展示、市场页手动出售
6. **Phase 6 — 平衡调试**：数值微调，确保三种资源间有足够张力

## 七、数值平衡参考

| 资源 | 每季产量 | 单价(基准) | 自用消耗(典型) | 剩余可售 |
|------|---------|-----------|--------------|---------|
| 黄金 | 2-4 | 50 | 0 (囤积) | 0-4 |
| 煤炭 | 8-12 | 5 | 3-8 (工厂+矿山) | 0-9 |
| 铜 | 5-7 | 8 | 3-10 (装备生产) | 0-4 |

**早期**（1904-1914）：煤炭和铜充裕，主要用于出售换现金
**中期**（1914-1935）：战时煤耗剧增，铜需求随装备升级攀升
**后期**（1935-1955）：三种资源全面紧张，外国矿战略价值凸显
