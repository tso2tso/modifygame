## 二、新评审发现的问题（6项）

### 问题1: 早期空窗 — 世界页解锁前的"旁观者困境"

**现象**: 游戏前8-12回合（总影响<20 且无区域控制≥50），世界Tab只有只读的地图和大国势力展示。玩家能看到世界在变化，但完全无法参与。

**严重度**: ★★★★☆（高） — 影响首次留存

**根因**: 分层解锁虽消除了悬崖，但第一层门槛（总影响≥20）仍需8-12回合才能达成，期间世界页完全被动。

**设计目标**: 从第1回合起就让玩家感受到"我与世界有关系"。

### 问题2: 远征"打地鼠"感

**现象**: 征服一个弱国需要反复点击Raid 8-10次，每次消耗2AP+200现金，单次伤害30-200（总HP 400-700）。过程机械重复，缺乏战略决策。

**严重度**: ★★★★★（极高） — 核心玩法之一体验差

**根因**: v1的"战线化"方案(P3)未实施，远征仍是单次行动模式。

### 问题3: 信息过载 — 15个大国数据墙

**现象**: 大国势力面板展示15个国家×3维度=45+数字，没有优先级排序。玩家不知道该关注谁、做什么。尤其对新玩家，打开世界页的第一反应是"信息轰炸"。

**严重度**: ★★★★☆（高） — 影响可理解性

**根因**: v1的"聚光灯模式"和"顾问建议"(P4)未实施。

### 问题4: 贸易认知成本 — 新玩家的第一笔交易障碍

**现象**: 贸易系统有路线安全度、运输成本、装备分配、护送编队等多个概念。虽然QuickFulfill简化了操作，但玩家需要理解"为什么安全度影响交付率"、"护送编队怎么来的"等前置知识。

**严重度**: ★★★☆☆（中） — 学习曲线陡峭但可克服

**根因**: 缺乏渐进引导，所有概念一次性呈现。

### 问题5: 合作度反馈延迟 — 抵抗路线的"信仰税"

**现象**: 合作路线（collaboration_score ≥ 10）从第一笔贸易就能获得+10%价格奖励，即时回报明确。抵抗路线（collaboration_score ≤ -30）的奖励是"解放后影响力+15"——这可能是40-50回合后的事。前期选择抵抗 = 纯粹牺牲收益，没有中期正反馈。

**严重度**: ★★★★☆（高） — 策略选择不平衡

**根因**: 合作度的正向/负向效果设计不对称。合作有即时经济回报，抵抗只有终局叙事回报。

### 问题6: 好感度缺乏自然衰减

**现象**: `attitude_to_player` 只增不减（除了负面行动），一旦通过几次合作行动积累到+50，就永久享受安全度加成和贸易优惠。缺乏"维护关系"的持续投入需求。

**严重度**: ★★★☆☆（中） — 削弱中后期策略深度

**根因**: 好感度模型只有"行动改变"，没有"时间衰减"。

## 三、v2 优化方案

### 方案A: 早期世界参与（解决问题1）

**目标**: 从第1回合起，玩家就有"轻量但有意义"的世界互动。

#### A.1 "世界观察"系统 — 零门槛被动收益

在大国外交行动解锁前（总影响<20），给玩家一个轻量级互动：**每季选择1个大国进行"关注"**（0 AP），获得：

- 该大国本季变化的详细报告（经济、军事、厌战度的变动原因）
- 微量情报收益（每季+1影响力，叠加到总影响，加速解锁第1层）

**设计意图**:
- 不改变核心节奏（不额外给AP/现金）
- 培养"关注世界局势"的习惯
- 给玩家一个"我在做选择"的感觉（选谁来关注）
- 加速第1层解锁（8-12回合缩短到6-8回合）

**实现范围**:
```
新增: scripts/systems/world_observe.lua（~80行）
  - WorldObserve.SetFocus(state, powerId) — 设置关注目标
  - WorldObserve.Tick(state) — 每季结算，生成报告+微量影响力
修改: scripts/ui/ui_world.lua
  - 在势力面板中为每个大国添加"关注"按钮（未解锁gp_actions时显示）
  - 关注中的大国高亮显示，展示详细变化报告
修改: scripts/systems/turn_engine.lua
  - 每季结算调用 WorldObserve.Tick
```

#### A.2 "历史快讯"自动推送

从第1回合起，每季结算后如果发生了重大世界事件（征服、继承、大国军事/经济剧变），自动弹出1条简短快讯：

```
"1906Q2: 德意志帝国军事力量增长至72（+5），正在积极扩军。"
"1914Q3: 塞尔维亚被奥匈帝国征服！波斯尼亚边境局势紧张。"
```

**设计意图**:
- 世界不再是"沉默的背景板"
- 帮助玩家建立"世界在动态变化"的感知
- 为后续大国外交行动建立认知基础

**实现范围**:
```
修改: scripts/systems/grand_powers.lua
  - Tick() 返回的 report 中增加 headline 字段（最重要的1条事件）
修改: scripts/ui/ui_event_modal.lua 或新增 scripts/ui/ui_world_news.lua
  - 每季结算后，如果有 headline，以 Toast 或底部横幅形式展示
  - 点击可展开查看完整世界报告
```

### 方案B: 远征战线化（解决问题2）

**目标**: 征服从"反复点击Raid"变为"开辟战线→持续推进→关键决策"。

#### B.1 战线机制核心设计

```
新概念: "战线"(Front)
- 创建: OpenFront(countryId) — 3AP + 500现金
- 持续: 每季自动对目标造成伤害（base_damage × power_ratio）
- 强化: Assault(countryId) — 1AP + 100现金，额外伤害（当季叠加）
- 终结: HP归零 → Occupy（3AP + 800现金，不变）
- 维护: 每条活跃战线每季消耗200现金

新概念: "战线等级"
- 持续时间越长，战线效率越高（Lv1→Lv3）
- Lv1(1-2季): 基础伤害×1.0
- Lv2(3-4季): 基础伤害×1.2 + 抵抗增长减缓
- Lv3(5+季): 基础伤害×1.5 + 占领费用-30%
```

**典型征服流程对比**:

| | 当前 | 优化后 |
|---|---|---|
| 弱国(Minor) | Raid×8次=16AP | OpenFront(3AP) + 自动推进2季 + Occupy(3AP) = 6AP跨3回合 |
| 中等国(Mid) | Raid×12次=24AP | OpenFront(3AP) + Assault×2(2AP) + 自动推进3季 + Occupy(3AP) = 8AP跨4回合 |
| 玩家决策 | "点不点Raid"×N次 | "何时开战、是否加强、何时占领" |
| 资源压力 | 每次200现金×N | 一次500+每季200维护+占领800 |

**设计意图**:
- 减少重复点击（8-10次→2-3次关键决策）
- 增加时间维度（征服需要跨回合规划）
- 增加资源权衡（维护费 vs 多线作战）
- 保留现有难度递增机制和前进基地加成

#### B.2 战线与系统耦合

- **贸易→战线**: 完成"军事物资"订单的 supply_boost 改为：活跃战线伤害+15%（已有机制适配）
- **外交→战线**: 对目标国宗主执行 support_guerrilla → 该国抵抗增长+5/季（已有），且战线推进伤害+10%（新增）
- **多线作战**: 最多3条同时活跃战线（超过则维护费翻倍）

**实现范围**:
```
大改: scripts/systems/expedition.lua（~400行重写）
  - 保留 HP 系统、难度递增、前进基地加成
  - 新增 OpenFront / CloseFront / Assault / TickFronts
  - 移除单次 Raid 作为独立行动（融入战线系统）
  - Support 行动保留但改为"对活跃战线的增援"
修改: scripts/ui/ui_world.lua — 远征子tab
  - 展示活跃战线列表（目标国、等级、HP进度、维护费）
  - 按钮从"突袭/支援/占领"改为"开辟战线/强化攻势/占领"
修改: scripts/data/balance.lua
  - 新增战线相关费用参数
```

  - 邻接大国

第3层 — 其他大国（仅显示名称+1行摘要）:

### 方案F: 好感度自然衰减（解决问题6）

**目标**: 好感度不再是"一劳永逸"，需要持续维护外交关系。

#### F.1 衰减机制

```lua
-- 每季结算时，对所有大国的 attitude_to_player 应用衰减
ATTITUDE_DECAY = {
    rate = 0.05,        -- 每季衰减5%（向0靠拢）
    threshold = 5,      -- 绝对值≤5时停止衰减（微弱好感/恶感持久）
    cap_per_turn = 3,   -- 单季最大衰减量（防止极高好感快速崩塌）
}

-- 衰减公式
local decay = math.min(
    math.abs(attitude) * ATTITUDE_DECAY.rate,
    ATTITUDE_DECAY.cap_per_turn
)
if math.abs(attitude) > ATTITUDE_DECAY.threshold then
    attitude = attitude - decay * (attitude > 0 and 1 or -1)
end
```

**设计效果**:
- 好感+50 → 4季后约+36（需要偶尔做合作行动维护）
- 好感+10 → 4季后约+7（微弱关系自然消退）
- 好感-30 → 4季后约-22（敌意也会缓解，除非持续对抗）

**策略深度**:
- 创造"维护外交关系"的持续AP投入需求
- 与AP紧张形成权衡：维护老关系 vs 开拓新方向

## 七、风险与缓解

| 风险 | 描述 | 缓解措施 |
|------|------|---------|
| 世界观察+1影响力加速过快 | 可能让第1层解锁提前太多 | 影响力增长设上限（每季最多从观察获得+1），或改为概率性获得 |

| 战线系统增加复杂度 | 新概念需要学习 | 首次开战前弹出教学引导，且前1-2次战线免维护费 |
| 好感度衰减过快 | 玩家感觉"白做了" | 衰减率5%足够温和（+50→4季后+36），且≤5时停止衰减 |
| P3远征重写风险 | 代码量大、测试面广 | 保留旧Raid逻辑作为fallback，用配置开关切换新旧系统 |
